# Regel-Spezifikation

Auswertung des **ALIEN RPG Core Rulebook, 1. Auflage 2019** für die Umsetzung in Xenoforge. Jede Regel steht mit der gedruckten Buchseite (`[p. N]`), jede Tabelle mit allen Zahlenwerten. Beschreibungen sind eigene Kurzformulierungen, keine Buchzitate.

**Vorrang:** [00-errata-und-festlegungen.md](00-errata-und-festlegungen.md) geht allen anderen Dateien vor.

| Datei | Inhalt |
| --- | --- |
| [01-characters.md](01-characters.md) | Spielmodi, Erschaffung, Attribute, Fertigkeiten, Talente, Agenda, Story Points, Ausrüstung, Traglast, Vorräte, XP, Karrieren, Androiden, Charakterbogen |
| [02-dice-skills-panic.md](02-dice-skills-panic.md) | Würfelmechanik, Push, alle Fertigkeiten mit Stunts, Stress, Panik, Traumata, Algorithmus und Testfälle |
| [03-combat.md](03-combat.md) | Zonen, Zeitmaß, Schleichmodus, Initiative, Aktionen, Nah- und Fernkampf, Schaden, kritische Verletzungen, Tod, Ablauf als Zustandsmaschine |
| [04-hazards-gear-vehicles.md](04-hazards-gear-vehicles.md) | Zustände, Vakuum, Feuer, Explosion, Krankheit, Strahlung, Synthetics, Fahrzeugkampf, alle Waffen, Rüstungen, Ausrüstung, Fahrzeuge |
| [05-ships-space-combat.md](05-ships-space-combat.md) | Reisen, Hyperschlaf, Schiffsklassen, Module, Bewaffnung, Upgrades, Wartung, Buchschiffe, Raumkampf |
| [06-creatures.md](06-creatures.md) | Allgemeine Kreaturenregeln, alle Werteblöcke und Angriffstabellen, Lebenszyklen |
| [07-gm-npc-campaign.md](07-gm-npc-campaign.md) | NSC, Cinematic- und Campaign-Spiel, Generatoren, Hope's Last Day, Bögen |

Die Dateien sind englisch, damit die Regelbegriffe genau denen im Buch entsprechen. Jede Datei endet mit „Ambiguities“, „Time-related rules“ und „State the app must track“.
